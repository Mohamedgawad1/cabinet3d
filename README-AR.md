تطبيق ويب واحد يعرض كابلات مشروع PS5 من ملف الجدول الحقيقي، ويرسم الكابينة
والأجهزة في 3D، ويوريك مسار كل كابل من البداية → الكابل → النهاية.

---

## 1) تشغيل التطبيق

```
cd C:\Users\mylap\Desktop
python -m http.server 8000
```

افتح: `http://localhost:8000/cabinet3d/index.html`

المجلد كامل مستقل (HTML + three.js محلي + بيانات) — مفيش إنترنت مطلوب.

## 3) زرار التحديث — نسبة إكمال النظام

فيه رقمين مختلفين، وكلٌّ منهما مكتوب مصدره بوضوح:

**أ) نسبة الجدول (شغالة دايماً، بدون إنترنت):**
محسوبة من ملف الـ tracker نفسه:
`2846 / 3919 = 72.6%` مسحوب، و `2772` مُنهى طرفه.

**ب) نسبة Smart Cloud (لحظية):**
من `https://wly04-sc.intergraphsmartcloud.com/.../Switchboard.htm`

الموقع ده محتاج تسجيل دخول، والمتصفح ما يقدرش يقرأه من localhost (CORS +
الكوكيز). عشان كده فيه جسر صغير بيقرأ بدالك من السيرفر:

```
python tools\progress_server.py
```

وبعدها:
1. افتح الموقع في المتصفح وسجّل دخول.
2. F12 → Network → أي طلب → Request Headers → انسخ `Cookie`.
3. انسخ الملف `tools\smartcloud.sample.json` باسم `tools\smartcloud.json`
   وضع الكوكي جوه.
4. اضغط زرار **⟳** في التطبيق.

لو الجسر مش شغال، الزرار بيقولك كده وبيسألك تدخل النسبة بإيدك (بتتحفظ)،
أو بيعرض آخر رقم محفوظ — مفيش أرقام وهمية.

## 4) مشاركة التطبيق أونلاين

**داخل الشبكة (أسرع وأأمن):**
```
http://192.168.3.18:8000/cabinet3d/index.html
```
أي جهاز على نفس الواي فاي يفتحه. (لو مش فاتح: اسمح لـ Python في Windows Firewall.)

**على الإنترنت — ngrok:**
```
ngrok http 8000
```
بيطلعلك رابط `https://xxxx.ngrok-free.app` — ابعت الرابط لأي حد. الرابط بيقف
لما تقفل النافذة. (شغّال عندك بالفعل.)

**استضافة ثابتة (Netlify / GitHub Pages / IIS):**
ارفع مجلد `cabinet3d` كامل. كل حاجة بتشتغل ما عدا زرار Smart Cloud (محتاج
الجسر). نسبة الجدول بتشتغل عادي.

## 5) صور الأجهزة من الموديل

لتصدير Render حقيقي لكل عائلة:

```
powershell -ExecutionPolicy Bypass -File tools\export_family_shots.ps1
```

* لازم Navisworks Manage يكون مقفول (الأتمتة بتفتح نسخة مخفية).
* أول تشغيل: بناء فهرس الموديل ~20 دقيقة، وبعدها ~15 ثانية لكل عائلة.
* الناتج بيتنسخ تلقائياً في `data\img\fam\`.

> ملاحظة: الأتمتة بترفض تبدأ لو فيه نسخة Navisworks مفتوحة أو لو الليسانس
> انتهى (`0x80080005`). افتح Navisworks مرة يدوياً واقفله، وبعدها شغّل السكربت.

## 6) الطباعة

اختار كابل من نتيجة البحث، وادوس **Print** (أو Ctrl+P) — بتطلع ورقة A4 فيها:

- FROM → الكابل → TO
- الكابينة + رقم الـ strip و slot بالظبط
- الـ subsystem و task ID والـ drawing
- صورة الجهاز في كل ناحية
- المسافة والنوع والمقاس

من غير ما تختار كابل، الطباعة بتطلع ملخص الموقع (الأعداد لكل عائلة).
